# Lemon 柠檬字词 —— 小学生默写练习微信小程序

给自家三年级孩子用的默写工具（青檬字词的个人复刻版），无登录、无支付、无广告。

## 功能规划

| 模块 | 内容 | 期次 |
|---|---|---|
| 柠檬字词 | 部编版词库 · 语音报默 · 拍照批改 · 错题本 | M1 |
| 柠檬单词 | 人教 PEP 单词 · 听音写词 · 闯关背诵 | M2+ |

## 技术栈

- 微信原生小程序（设计 token 见 `docs/M1-设计文档.md`）
- Turso（libsql）云端同步：`sessions` / `wrong_book` / `settings` 三表已建
- TTS：微信同声传译插件；OCR：腾讯云手写体识别（云函数代理）
- 词库 JSON 分包，主包 < 1MB
