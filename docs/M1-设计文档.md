# 柠檬字词 · M1 设计文档

> 定位：给自家三年级孩子用的默写练习小程序（人教版）。
> 自用产品：无登录、无支付、无广告。单用户本地优先，云开发只做存储兜底。
> 本期（M1）交付语文核心闭环 + 拍照批改；英语模块（柠檬单词）排 M2 之后。

---

## 1. M1 范围

核心闭环：**选词库 → 语音报默 → 批改（拍照识别 / 手动标对错）→ 错题本 → 复习卷**

不在 M1：默写卷导出打印、专项练习（同音字/形近字）、柠檬单词全部模块。

## 2. 页面结构（原生小程序，3 个 Tab）

```
TabBar
├── pages/index/index          首页
├── pages/wrong-book/wrong-book  错题本
└── pages/settings/settings    设置（家长）

普通页
├── pages/vocab/vocab          词库选择（年级固定三年级 → 上/下册 → 单元 → 表类型）
├── pages/dictation/dictation  语音报默（核心页）
├── pages/photo-check/photo-check  拍照批改
└── pages/review/review        复习卷报默（错题本一键生成，复用报默页逻辑）
```

### 2.1 首页
- 顶部柠檬黄信息头：产品名 + 「三年级 · 人教版」
- 今日任务卡：格子进度条 + 继续按钮（延续上次报默进度）
- 两大模块卡：柠檬字词（可用）/ 柠檬单词（M2 灰显「敬请期待」）
- 上周正确率统计卡（本地 storage 聚合）

### 2.2 词库选择
年级固定三年级 → 选上/下册 → 单元列表（1-8 单元）→ 表类型三选一：
- **识字表**（认读，报默选词）
- **写字表**（书写，报默主战场）
- **词语表**（两字/三字词报默）
选定后进报默页，可调词数（默认 10）。

### 2.3 语音报默页（设计稿已确认方向）
- 顶部：课次进度 + 暂停
- 格子进度条：绿=对 / 黄=当前 / 灰=未报
- 田字格书写区：报默时不显示字（只显示拼音提示可开关），批改时逐格显示
- 控制条：重听本词 / 报下一个 / 标错·标对
- 报默设置（设置页全局）：语速、报词间隔（默认 15s）、每词重复次数、顺序（顺序/随机）

### 2.4 拍照批改页
流程：报默结束 → 提示「拍照批改」→ chooseMedia 拍照/相册 → 云函数 OCR → 逐词比对 → 逐词确认页（自动预判 + 手动改判）→ 入库错题本。

### 2.5 错题本
- 错词列表：词 + 拼音 + 错误次数 + 最近错时间
- 一键生成复习卷：选数量（默认错词前 10）→ 进复习报默
- 错词「连对 3 次自动毕业」出池

### 2.6 设置页（家长）
教材版本、报默参数（语速/间隔/重复/顺序）、拼音提示开关、清空数据。

| key | 结构 | 说明 |

| `profile` | `{ grade: 3, term: 1, version: "人教版" }` | 当前教材 |

## 4. 拍照批改技术方案

- **OCR**：腾讯云**手写体识别**（HandwritingOCR）经云函数调用（云开发仅承担 OCR 代理一个职责，存储已由 Turso 接管），个人免费额度 1000 次/月，自用足够
- **比对算法**：识别文本按行/词切分 → 与本组词表比对：
  - 完全匹配 → 判对（绿）
  - 编辑距离 ≤ 1（漏字/多字/形近）→ 判「疑似错」（黄，待手动确认）
  - 未检出 → 灰色「未识别」
- **兜底**：识别失败或字迹潦草误判 → 逐词手动改判，流程永不卡死（用户已确认「拍照识别 + 手动」双轨）
- 腾讯云 OCR 需要密钥，存云函数环境变量，**不下发到前端**

## 5. 语音报默技术方案

- **TTS**：微信同声传译插件（WechatSI，`textToSpeech`，免费）
- 按词缓存音频文件路径，同词不重复请求
- 报词节奏：报词 → 停 `intervalSec` →（重复次数）→ 下一词；暂停/重听全局可控
- 儿童名字等自定义词可加进「自定义词表」（设置页录入）

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 词库数据错漏（拼音/漏词） | 人工对照电子课本逐单元校对；家长抽查 |
| 手写体识别对低年级字迹准确率有限 | 双轨批改兜底，识别只做「预判」不做终判 |
| 主包体积 | 词库全部放分包，主包 < 1MB |
| OCR 免费额度 | 1000 次/月自用充足；超了降级纯手动批改 |
