# 柠檬字词 · 设计文档 v2.0

> 取代 docs/M1-设计文档.md（v1.0，M1 阶段 3 Tab 蓝图，留档）。
> v2.0 对齐 0.5.0 实际实现：15 页面 + 云函数 ai 六 action + 语文四册 / 英语四册词库 + Agnes LLM。

## 1. 产品定位

「柠檬字词」微信小程序：给自家三年级孩子用的**语文报默 + 英语听写**自用工具。
复刻青柠字词（zjb.bjwxjs.com）核心能力，个人主体、无登录/支付/广告。

## 4. 数据结构

### 4.1 本地 storage（主存储，utils/store.js）

- `profile`：grade / term / version（年级切换即写）
- `settings`：speechRate / intervalSec / repeat / showPinyin / voiceType（白名单兜底 101001）
- `sessions`：报默记录（≤500 条），addSession 同时上云
- `wrong_book`：语文错题；英语错题池独立（连对 3 次出池）
- 自定义词表 / 断点续默

### 4.2 Turso 云兜底（v2/pipeline，token 在 gitignore 的 config.js）

| 表 | 用途 |
|---|---|
| sessions | id / created_at / unit / list_type / mode / total / correct / words_json |
| wrong_book | 语文错题镜像 |
| settings | 设置上云（savedAt 新者胜） |
| **sub_quota** | 订阅周报额度（openid PRIMARY KEY, granted_at），D⑦ 新增 |

### 4.3 词库（主包 JS 模块，require 不支持 JSON）

- 语文 `data/vocab/grade{3,4}/term{1,2}.js`：**tools/fetch_official_vocab.py** 从官方接口（pinyin.bjwxjs.com，area 10 写字 / 11 识字 / 1 词语）生成，勿手改
  - 三上 2026sanshang63 / 三下 0x9LIuj-TsOL-fXihJLmUg / 四上 2026sishang63 / 四下 oMVxiq8LSFipiaUL7WGKeQ
- 英语 `data/vocab/english/grade{3,4}-term{1,2}.js`：手工整理 PEP，6 单元 × 12 词

## 5. 云函数 ai（cloudfunctions/ai/）

| action | 能力 | 依赖 |
|---|---|---|
| tts | TextToVoice（ModelType 1 基础音色；403xxx 大模型音色已 PkgExhausted 弃用） | secret.json |
| ocr | GeneralHandwritingOCR 手写体 | secret.json |
| explain | 中/英词解读 → Agnes agnes-2.5-flash（OpenAI 兼容 /chat/completions） | llm.json |
| **poemImage** | 古诗配图 → agnes-image-2.5-flash（/images/generations），云函数侧下载转 base64 回传（规避 downloadFile 域名白名单）；storage 缓存 `poemimg:<title>` | llm.json |
| **subscribeReport** | 授权订阅后记录 openid → Turso sub_quota | turso.json |
| **weekPush** | 查 sessions 近 7 天聚合 → subscribeMessage.send 推送；43101 自动清额度 | turso.json + 模板 ID |

密钥文件均为 gitignore、随包部署：secret.json（腾讯云 TTS/OCR）、llm.json（Agnes）、turso.json（Turso）。
config.json：函数配置（timeout 60s；permissions.openapi 含 subscribeMessage.send）。

## 6. 已知约束与坑（重要，防重复踩）

1. **微信云函数 CLI 部署不应用 config.json 的 timeout**（info 恒显示 3s）——LLM/图像调用靠前端自动重试兜底（冷启动首调被杀 → 热实例 3-5s 成）。根治需在云开发控制台手动改超时 60s。
2. 大模型音色（403xxx/502xxx）计费池独立，资源包耗尽即 PkgExhausted 静默无声 → 只用基础音色 101xxx。
3. automator `callMethod` 在 reLaunch 后静默失效 → 导航/断言统一走 `evaluate`；`page.$` 穿不透自定义组件 → 用 `selectComponent`；evaluate 里 `require` 不可用。
4. dictionaryapi.dev 境外源不可达（已弃用，Agnes 替代）。
5. 主包体积：0.5.0 约 270KB 量级（四册语文词库全在主包），2MB 限额内；词库扩到六年级再考虑分包。
